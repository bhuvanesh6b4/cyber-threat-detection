📘 Configuration Guide

To enable each integration, set the corresponding variable in backend/.env (never in frontend code) and restart the backend:

  • Google Sheets (required): GOOGLE_APPS_SCRIPT_URL — see google-apps-script/Code.gs setup instructions in the README.
  • Text & Email Scanners (optional): GEMINI_API_KEY — without it, these scans use LOCAL DEMO MODE.
  • URL & File Scanners (optional): VIRUSTOTAL_API_KEY — without it, these scans use LOCAL DEMO MODE.
